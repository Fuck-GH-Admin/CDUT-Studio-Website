# 快速开始

CDUT Studio 是一款桌面 AI Agent 客户端，也提供面向成理学生的学习、浏览和校园工具。无需先理解模型、工作区或自动化的技术原理；建议先完成一次普通对话，再探索其他功能。

## 从这里开始

- [第一次启动与引导](first-run.md)：初次打开会看到什么。
- [完成第一项 Agent 任务](first-task.md)：创建会话、选择模型和提出问题。
- [安装与配置](../02-installation/index.md)：还没安装，或者模型尚未配置。

## 什么时候需要校园账户？

一般的 Agent 任务可以先使用你自己配置的模型渠道；**校园数据查询和 AI 速课堂**需要通过 CDUT 专区的特区账户登录。材料审核使用的是另外配置的审核模型出口，和校园账户不是同一个概念。具体要求见[校园账户](../03-features/campus-account.md)。

> 建议先用不含个人隐私的示例文件练习。涉及真实教务数据、重要申请或财务信息时，应先弄清权限和数据去向。

# 第一次启动与引导

第一次打开 CDUT Studio 时，客户端会带你经过欢迎页面、功能介绍、数据迁移选择和进入主界面的流程。**是否出现各步骤，以你安装的版本为准**。

## 操作步骤

1. 打开已安装的 CDUT Studio，阅读欢迎页面。
2. 选择 **了解 CDUT Studio 能做什么**，浏览功能导览；也可以按照界面提示跳过。
3. 如果此前已经使用过本软件，可以在 **导入已有数据** 环节选择导入备份；首次使用者可以跳过。
4. 完成欢迎引导，进入主界面。
5. 找到左侧的 Agent 工作区或 CDUT 专区入口，再决定下一步做什么。

## 两个容易误解的地方

**需要先登录校园账号吗？** 不需要。初次进入软件和使用自行配置的通用 Agent 不以校园账户为前提；校内工具另有登录要求。

**需要安装 Bun、Git 或自己运行源码吗？** 使用正常打包好的客户端不应照搬开发者 README 的 `git clone`、`bun install`、`bun run dev`。这些命令是开发环境步骤，不是普通学生的安装说明。

如尚未配置 AI 模型，请先读[模型渠道配置](../02-installation/model-setup.md)。

# 完成第一项 Agent 任务

Agent 不只是回答一句话：在获得相应权限后，也可以读取文件、使用工具或分步完成任务。第一次使用时，推荐从不涉及隐私和外部写入的任务开始。

## 试着完成一项简单任务

1. 先按[模型渠道配置](../02-installation/model-setup.md)确保至少有一个可用模型。
2. 回到 Agent 界面，新建会话或使用当前会话。
3. 选择一个已启用的模型。在没有把握时，保留需要审批的权限模式，不要直接采用完全自动。
4. 输入下面这样的需求：

   > 请帮我制定一份三天的无机化学复习计划。每天包含复习目标、练习安排和自测问题。

5. 阅读生成结果；不满意就补充课程范围、时间和难度。
6. 要让 Agent 阅读材料时，可通过添加文件入口附加材料，或使用 `@` 引用允许访问的文件。

## 认识几个常用入口

- **模型选择**：决定本次对话交给哪个模型处理。
- **权限模式**：控制工具执行是否需要确认。对未知操作，请优先选择保留审批的模式。
- **工作区**：用于组织文件与会话。未主动选择工作区时，客户端仍使用默认隔离工作区，而不是直接把整个个人主目录开放给 Agent。
- **Agent 技能**：后续可在这里管理 Skills、MCP、记忆与预设。

Agent 提出的结论仍需检查；它完成一个步骤，不等于外部网站或学校系统已经成功办理业务。下一步可阅读[完整 Agent 功能指南](../03-features/agent.md)。

# 下载与安装 CDUT Studio

## 1. 找到可信的下载来源

优先打开[官网 /download](/download)。如果官网暂时无法获取版本列表，可从[GitHub Releases](https://github.com/Nya-Angle/CDUT-Studio/releases)查看实际发布记录。

下载之前检查**发布名称、是否预览版、发布日期、操作系统、架构及附件名称**。有附件才能确认对应平台可下载；不要仅根据网站上展示的 Windows/macOS/Linux 图标推断已经发布。

## 2. 按平台安装

- **Windows**：如果该版本提供 Windows 安装程序（例如 `.exe`），先核对发布者与附件，再启动安装程序，按安装向导操作。若 Windows 弹出安全提醒，应先核实来源，**不要一概关闭安全防护**。
- **macOS**：仅在发布附件提供对应系统和架构的应用包时安装。按发布说明完成安装；若操作系统提出安全警告，先确认签名、文件来源与适配版本。
- **Linux**：仅在发布附件提供 Linux 构建时安装。不同格式（如 AppImage、deb 或压缩包）操作方法不同，应按照对应附件说明操作。

> **这里没有写固定版本号或三平台固定下载链接**。附件情况会变化，应该由下载页依据发布数据实时展示，而不是把某一次开发预览版当永久最新版。

## 3. 核对 SHA-256（如果发行方提供）

校验值能帮助你检测下载文件是否与发行方公布的文件一致，但**不能单独证明发行方可信**。先从可信发布页获取该附件对应的 SHA-256，再本地计算并逐字比较。

Windows PowerShell：

```powershell
Get-FileHash -Algorithm SHA256 "C:\\你的下载路径\\安装包.exe"
```

macOS 或 Linux 终端：

```bash
shasum -a 256 /path/to/downloaded-file
# 部分 Linux 发行版也可以使用：sha256sum /path/to/downloaded-file
```

校验不一致时不要安装；若发布方尚未公布校验值，网页不应展示凭空推导的校验码。

## 4. 安装后

首次启动可阅读[第一次启动](../01-getting-started/first-run.md)。如果启动失败、白屏或模型无法使用，跳转到[安装与连接问题](../04-faq/troubleshooting.md)。

# 配置 AI 模型渠道

CDUT Studio 的 Agent 需要能调用的 AI 模型。你可以按自己使用的服务商添加渠道，也可能在特定版本中看到由团队托管的可用渠道。**模型服务是否免费、是否计费，由该服务的实际规则决定，CDUT Studio 本身不会替第三方免除费用。**

## 1. 打开模型配置

在客户端进入 **设置 → 模型配置**（部分页面或旧版本可能显示为“渠道配置”）。

## 2. 添加一个渠道

1. 选择服务商/协议，例如 DeepSeek、Kimi、智谱、Ollama 或自定义兼容接口等。
2. 按界面提示填写渠道名称、必要的 API 地址（Base URL）与 API Key。不同服务商字段可能有所不同。
3. 使用 **测试连接** 检查是否能访问模型服务。
4. 获取或选择可用模型，确认启用状态。
5. 返回 Agent 界面，选择刚配置好的模型，试着发送一句简单的问题。

**API Key 从哪里来？** 从你选择的模型服务商控制台取得。CDUT Studio 不会凭空生成第三方渠道的密钥；不要使用来源不明的共享密钥。

## 3. 连接失败怎么查？

依次核对服务商、Base URL、Key、余额/额度、网络连通性和模型启用状态。检查后重新测试。模型没有出现在选择器里，通常先检查该渠道有没有被启用、模型有没有被勾选。

## 4. 校园专区的关系

通用 Agent 的模型配置与 **CDUT 特区账户**是两回事。校园数据需要有效的校内登录会话；材料审核还使用独立的审核模型出口，具体见[材料审核](../03-features/review.md)。

## 5. 关于密钥

客户端设计为将渠道配置和密钥保存到本机并加密，但你发给外部模型的文本、文件片段或其他数据，仍可能按渠道配置发送到服务商。**不要把密钥直接贴到聊天里，也不要把包含密钥的个人备份随意分享。**

# 更新、迁移与备份

## 更新软件

从[下载页](/download)或[GitHub Releases](https://github.com/Nya-Angle/CDUT-Studio/releases)查看版本说明，确认适配系统和重要变化后再安装新版。

如果你使用的是开发预览版，可能出现功能变化、兼容性问题或数据迁移。遇到跨版本升级，先做备份，不建议在重要审核或课程任务进行到一半时直接覆盖安装。

## 迁移和备份

客户端 **设置 → 数据管理** 包含数据导出/导入、存储用量和清理能力。首次启动引导中也可能提供“导入已有数据”。

建议顺序：

1. 打开旧版客户端，在 **设置 → 数据管理** 中导出一份个人备份。
2. 将备份保存到你信任的位置，不要发到公开群聊或公开仓库。
3. 安装目标版本，按引导或数据管理入口导入。
4. 核对模型渠道、常用工作区和重要会话是否可见，并重新测试外部服务连接。

**隐私提醒**：个人备份可能包含 API Key 或其他敏感设置；给他人共享配置时，不要直接分享个人备份，应核对是否有专门的去凭据分发选项。

## 版本不一致怎么办？

网站文章按核验基线撰写，不会覆盖未来所有发行版。遇到与截图/步骤不同的界面，请核对当前应用版本、当次发行说明和应用内的教程。必要时可以[提交问题](../04-faq/troubleshooting.md)。

# Agent 工作台

Agent 是 CDUT Studio 的通用 AI 工作区。它适合整理资料、制定计划、分析文件或执行允许范围内的工具任务。

## 基本使用

1. 在[模型配置](../02-installation/model-setup.md)中确保已添加可用渠道。
2. 在 Agent 工作台创建或打开一个会话。
3. 按需要选择工作区、模型和权限模式。
4. 在输入框直接描述目标；如果任务涉及文件，可使用文件添加入口，或输入 `@` 选取已授权的文件或目录。
5. 运行时注意查看工具请求、进度和结果；涉及修改文件、执行命令、外部网站操作时应先检查授权范围。

## 怎样提问更容易成功？

尽量同时告诉 Agent **目标、提供的材料、输出形式和限制**。例如：

> 请根据我附加的课程大纲，整理四天复习安排。每天列出知识点、练习时间和自测题。不要读取工作区以外的文件。

## 常用能力

- **工作区**：用于存放相关文件和会话。单个会话可以只围绕一个目标。
- **权限模式**：存在自动审批、完全自动和计划模式等选择。初次使用建议让敏感动作保留人工确认；计划模式适合先看方案再执行。
- **引用**：`@` 文件/目录、`/` Skills、`#` MCP、`&` 其他会话（具体入口受当前模式限制）。
- **任务进度**：任务图、目标状态等界面用于观察步骤和必要时暂停、停止。
- **会话分支**：可从历史消息处分叉或探索，避免把不同问题无限堆到同一条长对话。

## 请特别注意

AI 可能误读材料或执行与预期不一致的步骤。对涉及覆盖文件、发送消息、提交申请等操作，应先备份或审查。不要把 API Key、密码、验证码放进普通聊天。

延伸阅读：[技能、记忆与规划](skills-planning.md)。

# 登录 CDUT 特区账户

CDUT 专区提供与校园服务相关的入口。部分功能需要你以**本人学工号和密码**完成校内统一身份认证。登录校内系统并不意味着 CDUT Studio 是学校官方应用。

## 登录步骤

1. 打开客户端的 **CDUT 专区**。
2. 在特区账户卡片输入本人学工号、登录密码。
3. 如有必要，可选择 **记住密码**；不需要可不勾选。
4. 点击界面中的连接/登录操作，阅读客户端显示的登录结果。
5. 成功后可看到个人资料信息和专区功能入口。如果头像或个别字段为空，不代表登录没有成功。

## 为什么每次打开都要再登录？

按核验过的客户端用户指南，客户端每次启动都会复位校内登录会话。选择记住密码后，可以利用保存的凭据进行**一键填充并登录**，不等于开机静默自动登录。

## 登录状态何时会失效？

客户端会按间隔检查教务登录状态。学校端会话过期或认证失效时，你可能需要返回专区重新登录。若正在填写重要业务，请避免把“软件显示已发送请求”直接当成最终办理成功。

## 如何退出？

使用 **退出特区账户**。客户端的设计是清除本地保存的加密凭据，并停止该账号的登录保活和专属浏览分区。

> **密码安全**：只在明确的校园认证流程中输入凭据；不要把密码发到 AI 对话框、群聊或陌生网站。如果不信任当前软件版本，先不要绑定校园账户。

下一步：[校园事务工具](campus-tools.md)。

# 使用校园事务工具

完成[特区账户登录](campus-account.md)后，可以在 Agent 会话中用自然语言描述校园相关需求。客户端的实现包含课表、成绩、考务、教室、培养方案、选课等工具；**实际可用程度仍取决于学校系统页面、当前权限与安装版本**。

## 先从查询开始

例如：

> 查一下我本周的课表，按周一到周日列出课程时间、地点和教师。

> 看看周二下午第三教学楼有哪些空教室，优先找连续两节空闲的教室。

> 请把我当前可查询到的考试安排按日期整理成清单。不要进行报名操作。

读到结果后，留意是否提示登录失效、数据不足或查询失败；必要时以学校官方系统为准。

## 有哪些能力？

源码和内置教程涉及：学籍信息、课表、成绩及绩点计算、考务、空教室、培养方案、选课结果、教务通知等。部分工具还具备申请或报名类写入接口，例如选课、退课、缓考申请等。

## 申请、报名或修改信息时

**不要直接把 AI 回复里的“成功”当作办结结果。** 客户端当前写入操作设计有二次确认，但其成功识别存在依据网页文本判断的局限。正确做法：

1. 先让 Agent 展示它准备做什么、所需条件与数据。
2. 阅读并确认关键字段，再决定是否授权操作。
3. 操作完成后，**返回学校官方系统查看最终记录或通知**。
4. 如果信息不一致，不要重复提交，先联系对应部门核实。

## 当前容易误会的入口

CDUT 专区首页的某些课表、成绩快捷胶囊，在被核验的内置教程中仍为占位入口。需要查询时，建议在 Agent 会话中直接描述需求。

> 这里不提供绕过学校权限、自动批量提交或替他人访问账户的操作指南。

# AI 速课堂

AI 速课堂用于围绕课程材料进行讲解与学习整理。它不是学校课程平台，也不会自动保证题目正确或学习效果。

## 1. 进入课堂

1. 在 CDUT 专区[登录特区账户](campus-account.md)。
2. 点击 **AI 速课堂**。
3. 在弹出的 **选择学习课堂** 对话框中选择历史课堂，或点击 **开始新课堂** 并填写课程名称。
4. 进入后，如果想换一门课，使用顶部 **切换课堂**。

每个课堂有独立的资料和对话，适合按课程拆分学习内容。

## 2. 导入学习资料

在课堂左侧选择 **拖拽或点击上传学习资料**，可以添加课件、教材和笔记。当前用户指南列出的可处理格式包括 PDF、常见 Word / PowerPoint / Excel 文件、Markdown、HTML、文本及部分图片格式。

资料导入成功后会出现在 **已上传资料** 列表。需要它参与检索和讲解时，确认对应的资料已激活；不想让某份资料参与当前学习，可关闭激活状态。

> 图片和扫描版 PDF 的文字识别有额外限制：核验过的用户指南说明随包没有提供 OCR 资源，图片会降级为多模态视觉输入；不能期待每一张扫描页都能准确提取全文。

## 3. 从材料开始学习

你可以试着询问：

> 根据我激活的资料，讲解第一章中的核心概念。每个结论尽量给出原文位置，不确定的内容请说明。

> 请根据第二章内容先出五道基础自测题，等我作答后再解释错题。

部分回答提供原文依据定位。点击引用后可查看相应的文件或段落，但仍应与原文核对。

## 4. 资料树、抽认卡与测验

左侧 **资料树**是按需生成的，不会因为导入新资料就自动出现；需要先选择相关资料，再主动生成。右侧课堂区域包含导图、资料预览、抽认卡和测验等功能入口（可用项以当前版本为准）。

## 5. 常见问题

- **打不开**：先检查特区账户是否登录、是否在专区里选择课堂。
- **上传了却没引用**：检查资料是否解析成功并处于激活状态。
- **资料树是空的**：资料树需要手动生成。
- **生成结果有错**：回到原课件定位核对，不要直接把生成答案作为课程或考试官方答案。

# 智联万站与砚小龙

**智联万站**是 CDUT Studio 内置的网页浏览区域，提供地址栏、标签页和部分校园服务书签。它并不只允许访问校园网站，普通 `http` / `https` 网址也可访问。

## 打开网页

1. 在 CDUT 专区进入 **智联万站**。
2. 使用页面中的地址栏输入网址，或点击预设书签。
3. 通过标签栏在不同网页间切换。
4. 如果遇到页面加载失败，可考虑使用页面提供的 **净化缓存并重试**，或先在系统浏览器检查网络与网站状态。

地址栏主要用于打开网站，不等同于互联网搜索框；输入普通网址时，浏览器会尝试补齐 `https://`。

## 让砚小龙帮忙

智联万站中会出现可交互的桌宠 **砚小龙**。你可以向它描述当前网页中的目标，例如：

> 帮我看看这个网页有哪些栏目，并指出课程安排的入口。先不要提交表单。

砚小龙的设计重点是网页内的导航、读取、点击与填写等操作；它不等同于有权访问全部本地文件的通用 Agent。

## 设置砚小龙

右键立绘可以打开设置菜单，调整显示位置、形态、对话框朝向以及记忆相关选项。模型可以在 **设置 → 模型配置 → 智联万站专属模型** 中单独配置，未配置时按客户端默认规则处理。

## 注意事项

- 遇到登录、付款、申请提交或个人信息填写，应先核对页面真实地址、字段和授权范围。
- 网站可能更新结构或增加验证码，自动化可能因此失败；不要把无法执行归咎为你操作错误。
- 砚小龙的浏览器操作与校内事务工具是不同路径。对重要学校业务，请在官方网页核实结果。

# 材料审核

材料审核适合在递交正式申请前，**辅助检查材料与审核依据之间是否存在缺项或不一致**。它不会替代学校部门的审核决定。

## 1. 准备材料

使用审核工作台时，先分清三类文件：

| 类型 | 放什么 |
| --- | --- |
| **审核依据** | 你要遵循的通知、政策、格式规范或规则 |
| **待审文件** | 你准备提交的申请表、说明、申报文档 |
| **证明材料** | 证书、成绩证明或其他证据 |

导入前检查文件是否清晰且属于同一次申请，不要混用不同年份、不同学院的规则。

## 2. 开始预审

1. 打开 CDUT 专区的 **材料审核**，进入预审工作台。
2. 分别导入依据、待审文件、证明材料。被核验的用户指南指出工作台单文件上限为 **50 MB**，具体以当前版本的界面报错为准。
3. 让系统从依据中生成 **规则大纲**。
4. 继续进行 **可审核条目识别**。
5. 执行审核，等待问题卡及相关定位展示。
6. 根据问题卡，回到原文核对每一项，并对不清楚的部分进行人工检查。

## 3. 如何读三栏结果？

工作台以 **审核依据｜申请与证明｜AI 审核员** 为主体。问题卡可以关联原文定位和严重程度，但**颜色、分数或“已审核”数量不能当成已经完成全部事实核实的保证**。

审核结果只是预审意见。遗漏的证明、扫描质量差、规则本身过期、模型误判，都可能影响结论。

## 4. 导出报告

在一次审核完整结束后，如果案卷内容没有再变化，可以按界面操作导出预审报告。被核验的实现会生成 **JSON 和 Markdown** 报告；修改过案卷后，旧结果可能提示已过期，需要重新审核。

## 5. 功能限制（请务必阅读）

- 当前预审主线与进阶 **V2 案卷/模板编排/批次管理** 是两套不同成熟度的功能，后者部分流程尚未完整接入界面。
- 扫描图片 OCR 随包资源尚不完整，不能把“上传成功”当成“文字已成功识别”。
- 自建案卷里的证明卡不会自动变成“事实已识别”状态。
- 预审模型渠道受单独的出口类型约束；没有配置可用的审核模型时可能无法运行。
- 系统不是学校官方审核平台；正式申请以发布单位要求和原系统记录为准。

常见问题：[为什么报告不能导出？](../04-faq/troubleshooting.md)

# 技能、记忆与规划

学会基础 Agent 后，可以逐渐探索 Skills、MCP、记忆和定时任务，不必一开始就启用全部功能。

## Skills（技能）

**Agent 技能**区域可以管理工作区使用的 Skills。这些技能会告诉 Agent 如何处理特定任务，例如生成文档、表格或演示文稿。使用第三方 Skill 前应核对来源和权限，尤其留意它是否要求运行命令或发送文件。

## MCP（外部工具连接）

MCP 让 Agent 连接额外服务。添加后先测试连接，再启用；测试成功也不代表允许它访问一切内容。查看每个工具需要的授权，按最小权限配置。

## 记忆与预设

记忆适合保留工作区长期有效的背景和习惯；预设则用于保存常见任务的提示词、权限模式和工具配置。对一次性需求，不一定需要长期记忆。

## 规划中心

客户端提供 Todo、日历以及定时任务管理。比如，你可以把考试复习拆成待办，再按计划检查进度。

定时任务可能在未来自动调用模型与工具，并产生费用。设置前应确认工作区、模型、权限和失败后的处理方式。**不要在定时任务描述里写账号密码、验证码或 API Key。**

## 数据去哪里？

工作区与配置以本机为主，但第三方模型调用、远程连接和外部 MCP 可能需要联网。不同能力涉及的数据边界不同，详情见[隐私与安全](../04-faq/privacy.md)。

# 安装与使用问题排查

## 安装包打不开或启动白屏

先确认下载来源、操作系统、系统架构和附件格式是否匹配；如果发行方提供校验值，按[下载与安装](../02-installation/download-install.md)核对。不要随意关闭系统防护。如果同一版本持续失败，请记录系统版本、错误提示及可复现步骤反馈。

## 模型选不到、一直连接失败

打开 **设置 → 模型配置**，核对渠道是否启用、所需的模型是否已勾选、API 地址与 Key 是否填写正确，再运行连接测试。注意第三方服务可能受到余额、配额或网络环境影响。

## CDUT 专区登录后仍提示未登录

校园会话可能已过期。返回专区重新登录；勾选“记住密码”也不等于永久登录。不要反复把密码发给 Agent 请求代登录。

## 登录成功，但姓名或头像缺失

部分资料可能无法从校内页面读取；被核验的客户端设计会保留空白或使用受控缓存，不会伪造信息。可稍后重试，关键身份信息仍以学校官方系统为准。

## 专区首页“课表/成绩”快捷卡片点不动

被核验的内置用户教程明确注明部分底部快捷入口仍为占位。登录后，可尝试在 Agent 会话里直接提出课表、成绩或空教室查询需求。

## AI 速课堂打不开，或资料没有参与回答

首先检查是否已经登录特区账户、是否进入了有效课堂；再检查资料是否解析完成、已激活。**资料树需要手动生成**。

## 扫描件上传成功却没有识别文字

导入文件不等于 OCR 必然成功。当前用户指南记载随包未提供相关离线识别资源，图像会以视觉资料方式参与部分模型操作。建议补充清晰可复制文字版，并自行复核。

## 材料审核报告无法导出

必须有一次完成的审核，且审核之后案卷未被修改；如果材料变化导致结果过期，请重新审核。不要在未排查前反复点击导出。

## 砚小龙打不开网页或反复操作失败

先确认网站在系统浏览器是否可打开，再尝试内嵌浏览器的刷新或“净化缓存并重试”；网页更新、登录失效或验证码可能导致自动操作失败。

## Agent 读不到文件、结果偏离目标

检查工作区、附加文件权限和 `@` 引用路径。长会话可整理关键结论到工作区文件后新建会话继续。执行了错误操作时，先停止后续写入，再检查文件改动记录与可用回退点。

## 反馈问题时应提供什么？

软件版本、系统及架构、操作步骤、期望结果、实际结果、脱敏错误截图。不要公开贴出 Token、API Key、教务学工号、密码、真实成绩单或尚未公开的申请材料。

# 隐私与安全

CDUT Studio 的设计倾向于本机管理配置和会话，但**本地保存不等于所有数据都不会离开设备**。使用前，建议区分下面几种不同的数据流。

| 数据 | 应当知道什么 |
| --- | --- |
| 校园登录凭据 | 客户端设计为向校内认证流程提交，并在勾选“记住密码”时加密保存在本机；校内登录不是第三方模型的密码授权 |
| 模型 API Key | 保存在本机的渠道配置中，按客户端实现加密；不要分享到聊天或公开仓库 |
| 发送给 AI 模型的内容 | 根据所选模型渠道，问题、文件片段或其他上下文可能发送至对应服务商 |
| 审核材料 | 预审依赖允许的审核模型出口，敏感材料是否能交给该出口需要自行判断与确认 |
| 浏览器页面与自动化 | 浏览器工具可能读取当前页面、点击或填写表单；实际网站仍可能记录操作 |
| 个人备份 | 可能含模型密钥等敏感配置，只应存放在可信位置 |

## 保护自己的四个习惯

1. 不要向普通 AI 对话输入校园密码、API Key、短信验证码或他人的隐私资料。
2. 涉及教务查询、申请提交时，使用本人账号，阅读最终确认内容，并返回学校官方系统核对结果。
3. 添加第三方 Skills、MCP 或远程机器人前，检查其来源和请求的权限。
4. 遇到不明链接、非官方安装包或要求关闭安全功能的提示，先核实再操作。

## 学校官方关系

CDUT Studio 是学生和开源贡献者参与开发的**非官方项目**，不是成都理工大学授权的教务认证或审批渠道。它对校园系统的访问情况可能因学校政策、认证方式和网络环境变化而改变。

想了解项目的开源许可证，参见[关于项目](../06-about/index.md)。

# 关于 CDUT Studio

**CDUT Studio** 是面向成都理工大学校园使用场景的桌面 AI Agent 项目，由学生与开源贡献者开发。它把通用 AI 工作台、AI 速课堂、智联万站和材料审核等能力组织在同一客户端中。

## 它是什么？

一款需要安装到个人设备上的桌面应用。与纯网页教程不同，实际功能运行在客户端中；**官网负责介绍、下载和提供帮助，不是一个可直接登录并使用全部功能的在线教务系统**。
